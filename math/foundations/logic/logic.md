# #english-note 
## truth assignment
a truth assignment $\varphi$ is a mapping $$\varphi: \{ p_{1},p_{2},\cdots \}\to \{ T,F \}$$
### tautology
a formula $A$ is a tautology if $$\varphi (A)=T\forall \varphi$$
#### tautological implication
let $A,B$ be formulas and $\Gamma$ be a set of formulas
$$A\vDash B \iff (A\implies B)$$
$$\Gamma\vDash A \iff ((\varphi(B)=T\forall B\in \Gamma)\forall \varphi \implies A)$$
