## type I
### n-groups
let $G=\bigcup\limits_{k=1}^{n}G_{k}$ where $n\geq2$ where each $(G_{i},*_{i},e_{i})$ is a group with $*_{i}$ the binary operation and $e_{i}$ the identity element, st $G_{i}\neq G_{j}$ if $i\neq j,1\leq j,i\leq n$, further $G_{i}\not\subset G_{j}$ or $G_{j}\not\subset G_{i}$ if $i\neq j$. any element $x\in G$ would be represented $x=\bigcup\limits_{k=1}^{n}x_{k}$, where $x_{i}\in G_{i}$ 
$$x*y=\bigcup\limits_{k=1}^{n}x_{k}*_{k}y_{k}$$
$$e=\bigcup\limits_{k=1}^{n}e_{k}$$
