## set vector spaces
let $S$ be a set and $V$ another set. $V$ is a set vector space over $S$ if $\forall v\in V,s\in S$ $vs,sv\in V$
### linear magnification
if $v\in V,s\in S$ and $vs>v$ then it is a magnification
### set vector subspaces
let $W\subset V$, if $W$ is also a set vector space, then it is a set vector subspace of $V$
#### subset vector subspaces
let $V$ be a set vector space over $S$, $T$ be a proper subset of $S$ and $W$ a proper subset of $V$, if $W$ is a set vector space over $T$, then $W$ is a subset vector subspace of $V$
### generating set
let $V$ be a set vector space over $S$ and $B\subset V$ 
$B$ is a generating set of  $V$ over $S$ if $\forall v\in V\exists s\in S,b\in B$ st $v=sb$
